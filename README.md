# ShoppyGlobe

ShoppyGlobe is a basic e-commerce application built using React and Vite.

## GitHub Repository

https://github.com/Deepakkrcse/ShoppyGlobe.git

## Technologies Used

- React
- Vite
- Redux Toolkit
- React Redux
- React Router
- JavaScript
- CSS
- DummyJSON API

## Features

- Product listing
- Product search
- Product details
- Add products to cart
- Remove products from cart
- Increase product quantity
- Decrease product quantity
- Cart total
- Checkout form
- Order summary
- Order confirmation
- Automatic redirect to Home
- 404 page
- API error handling
- Lazy loaded components
- Lazy loaded images
- Responsive design

## API

Products:

https://dummyjson.com/products

Product details:

https://dummyjson.com/products/{id}
